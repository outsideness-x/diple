# CLAUDE.md — Архитектурные инварианты

1. Readium API не угадывается. Для парсинга EPUB используется Streamer, для отображения — EPUBNavigatorViewController. Перед использованием любого метода читай исходники в .build/checkouts или документацию пакета.
2. Файловая система: Файлы импортируются через .fileImporter и ОБЯЗАТЕЛЬНО копируются в Documents/Books/<uuid>/. Читать напрямую по URL из fileImporter нельзя — потеряем доступ.
3. Никаких хардкодных frame и подобранных на глаз паддингов ради «правильного скриншота». Вёрстка обязана переживать Dynamic Type и смену размера шрифта.
4. В этой итерации мы НЕ пишем генерацию фикстур. Я буду тестировать приложение на своих реальных файлах.

## Правила проекта
- Никаких force unwrap вне тестов.
- Каждое неочевидное решение — строкой в CLAUDE.md.
- Русский и корейский текст в метадате и книгах обязаны корректно отображаться.
- Спроси меня перед тем, как: менять модель данных, добавлять зависимость, отклоняться от порядка шагов.

## Неочевидные решения

### Readium
- `locationDidChange` объявлен в `NavigatorDelegate` с первым параметром `Navigator`, а не
  `VisualNavigator`. Если сузить тип, Swift примет это как самостоятельный метод, Readium
  продолжит вызывать пустую реализацию по умолчанию, и приложение не получит ни одного
  обновления позиции — молча. Это ломало прогресс, сохранение позиции и закладки сразу.
- `EPUBReflowableSpreadView.setupWebView()` выключает `bounces` и `alwaysBounceVertical`.
  Без принудительного включения обратно перепрокрутка за край главы физически невозможна.
- Каждый ресурс EPUB живёт в своём web view внутри горизонтального `PaginationView`.
  Spread view переиспользуются, поэтому привязку к скроллу нужно обновлять при смене
  локации и при создании новых spread'ов (`setupUserScripts`).
- В режиме скролла `disablePageTurnsWhileScrolling: true`: горизонтальный свайп не должен
  перелистывать главы, когда чтение вертикальное. Смена главы — вытягивание за край
  (`ChapterPullTransitionController`).
- `totalProgression` есть только у публикаций со списком позиций. Для остальных прогресс
  считается по индексу ресурса в `readingOrder`.
- Навигатор сообщает локацию на каждый прокрученный пиксель. Запись в SQLite на каждое
  событие ощутимо дёргает скролл — запись коалесцируется и уходит с главного актора,
  синхронный сброс только при закрытии читалки.

### UI
- Полоски оверлея читалки не могут быть чистым `Material`: он берёт тон у страницы, и на
  светлой/сепия теме светло-серые контролы на нём перестают читаться. Нужен тёмный тинт
  поверх блюра (`readerBarBackground()`).
- `Button` внутри `label:` другого `Button` не получает нажатий в SwiftUI — внешняя кнопка
  забирает тап. Строки списков с действием «удалить» строятся из соседних кнопок.
- Теги пользователя произвольной длины, `HStack` их обрезает. Строка тегов раскладывается
  собственным `Layout` (`FlowLayout`), который переносит элементы на следующую строку.
- Плейсхолдер обложки печатает название и автора, и его собственный контент выше, чем
  миниатюра в строке списка. Без `isCompact` он вылезает за свой `frame` и рисуется
  поверх карточки. Миниатюры берут размер из `@ScaledMetric`, чтобы переживать Dynamic Type.
- Обложки читаются внутри `body`, который пересчитывается при каждой прокрутке сетки —
  декодирование с диска кэшируется в `CoverImageCache`.
